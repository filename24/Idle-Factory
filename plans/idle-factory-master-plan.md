## 0. 비전 & 게임 컨셉

**Idle Factory**는 Discord에서 슬래시 커맨드로 즐기는 방치형 공장 경영 게임이다 (Idle Tycoon 모티브). 봇이 서버에 들어오면 유저는 자기 토지에 공장을 짓고, 자재를 생산·거래하며 **서버 단위를 넘는 글로벌 경제**에 참여한다.

핵심 차별점 (`docs/design/01-overview.md`):

- **수요·공급 기반 가격 변동** — 유저들의 실제 거래가 글로벌 시세를 움직인다
- **서버 단위 신뢰도·세금** — 서버 공동체의 활동이 개인 혜택(공장 등급 상한, XP 보너스)으로 돌아온다
- **닫힌 경제 순환** — 세금·직구매 할증·희귀 원자재 영구 소모·비활성 서버 재분배로 인플레를 제어한다

코어 루프: **건설 → 10분 tick 자동 생산 → 창고 저장 → 수확 → 판매/업그레이드/신축 → 글로벌 경제(마켓·주식·세금) → 서버 혜택/패널티 → 다시 생산**.

## 5. 로드맵 재구조화

기존 #4 구조를 유지하되 다음을 조정한다:

1. **#16 "주간 세금"과 Phase 3 "자산 누진세"는 통합** — 설계상(07) 주간 세금이 곧 자산 누진세라 분리 구현이 불가능하다. 누진세는 Phase 2로 흡수하고, Phase 3의 #17은 신뢰도·재분배·긴급지원에 집중한다. _(→ 이슈 #16/#17 스코프 갱신 완료)_
2. **#17의 Phase 2/3 중복 기재 정리** — 신뢰도 시스템 전체를 Phase 3로 일원화. 단 **weeklyDAU 집계 축적은 Phase 2 정산 잡에 선행 탑재**한다(#17의 신뢰도 공식이 주간 DAU를 입력으로 요구하므로 데이터가 미리 쌓여야 함).
3. **신규 항목 추가** (기존 로드맵 누락분):
   - 스케줄러 인프라 전환 (Phase 2 선행 과제)
   - 공장 로스터 완성 5종 (D-3)
   - TradeLog 기록·XP 정합·사기방지 v0
   - 토지 마무리 — `/land move` 구현·다구역 QA (구역 2~5 구매 자체는 Phase 1에서 선행 구현 확인됨 — 2026-07-03 정정)
   - 배포 파이프라인 (D-4)
   - CI 통합 테스트 편입 + 커버리지 게이트
   - 설계 문서 정리 (모순 11건·미정의 8건)
   - 경제 밸런스 시뮬레이터 (#21의 선행 도구)
4. **#20 웹 대시보드는 Phase 6에서 분리해 병렬 트랙(W)으로 조기 이행** — 봇 DB 읽기 전용이라 봇 개발과 충돌이 없고, 로그인→404 문제가 이미 사용자에게 노출되는 상태다.

## 6. Phase별 상세 플랜

### Phase 4 — 주식

**선행: 스키마 보강 마이그레이션** — 현재 스키마로는 설계 요구를 못 채운다:

- `Stock.dividendRate` 부재, `StockHolding.avgBuyPrice`(손익 계산 필수) 부재
- 종목별 체결량 집계 불가(TradeLog에 stockId 없음) → `stockId` 컬럼 추가 또는 별도 체결 로그
- `Stock.weeklyProfit`을 채울 공장 수익 집계 파이프 부재 → 수확·판매 시 수익 적립 경로 설계

이후: 상장(자동 검증 — 자산 평가 로직 재사용, **상장 단위는 스키마 현행대로 "공장"** — 유저가 자기 공장을 상장, 설계 문서의 유저/공장 혼선은 문서 쪽 통일), 매매 커맨드, 1시간 가격 tick 잡(0-나눗셈 가드 — U-5), 주간 배당(2.5 정산 잡 확장), 일일 ±30% 서킷브레이커.

**Exit**: 상장→매매→배당 1주기 완주, 가격 tick이 체결량에 반응.
