**Idle Factory**에 오신 것을 환영합니다! Discord 봇으로 공장을 짓고, 자재를 생산하고, 글로벌 시장에서 거래하는 방치형 산업 경영 게임입니다.

<Callout type="info" title="빠른 시작">
  Discord 서버에서 `/공장` 명령어를 입력하면 바로 게임을 시작할 수 있습니다.
</Callout>

## 핵심 개념 요약

| 항목          | 내용                             |
| ------------- | -------------------------------- |
| **생산 주기** | 1틱 = 10분, 공장이 자동으로 생산 |
| **티어 구조** | T1 원료 → T2 가공 → T3 완제품    |
| **창고**      | 꽉 차면 모든 공장 정지           |
| **레벨 조건** | T2: Lv.5 / T3: Lv.10 이상        |
