# Idle Factory 플레이어 가이드

**Idle Factory**에 오신 것을 환영합니다!

이 가이드는 게임을 처음 시작하는 플레이어부터 고급 전략을 원하는 플레이어까지 모두를 위한 공식 문서입니다.

## 시작하기

왼쪽 사이드바에서 원하는 항목을 선택해 읽어보세요.

- **시작하기**: 게임 소개, 봇 설치, 첫 번째 공장 건설
- **시설 관리**: 공장 종류, 토지 시스템, 창고 관리
- **경제 시스템**: 글로벌 마켓, 주식, 거래 전략
- **심화**: 레벨 시스템, 서버 신뢰도, 고급 전략

## 빠른 시작

Discord 서버에서 `/factory` 명령어를 입력하면 바로 게임을 시작할 수 있습니다.
