플레이어가 직접 회사를 상장하고, 다른 플레이어의 회사 주식을 매매할 수 있습니다.

## 주식 상장 (IPO) 조건

<Callout type="info" title="상장 요건">
  모든 조건을 **동시에** 충족해야 `/주식 상장`이 가능합니다.
</Callout>

| 조건           | 기준        |
| -------------- | ----------- |
| 레벨           | Lv.25 이상  |
| 보유 공장 수   | 5개 이상    |
| 총 자산        | 1억 원 이상 |
| 최근 30일 거래 | 10회 이상   |

## 글로벌 주식 (서버 간)

<Callout type="warn" title="아직 지원되지 않음">
  글로벌(서버 간) 주식 거래는 현재 지원되지 않습니다. 모든 상장 종목은 상장한 서버 안에서만 거래할
  수 있으며, 다른 서버의 유저는 참여할 수 없습니다.
</Callout>

추후 지원될 경우 플레이어 레벨 **Lv.40 이상**, 서버 신뢰도 **1,500pt 이상** 조건이 추가될
예정입니다.

## IPO 가격 설정

```math
P_{\text{IPO}} = \frac{\text{총자산} + \text{최근 30일 수익} \times 10}{100}
```

설정 가능 범위: $$0.3 \times P_{\text{IPO}} \leq P \leq 0.7 \times P_{\text{IPO}}$$

## 주가 변동

주가는 **1시간마다** 자동으로 갱신됩니다.

```math
P_{t+1} = P_t \times \bigl(1 + \Delta_{\text{수요}} + \Delta_{\text{수익률}} \times 0.3\bigr)
```

<Callout type="info" title="서킷 브레이커">
  하루 최대 **±30%** 범위 제한이 적용됩니다.
</Callout>

## 배당

보유 주식에 대해 **매주 일요일 자정**에 배당이 지급됩니다.

```math
\text{배당} = \frac{\text{주간 수익} \times 0.1}{\text{총 주식 수}} \times \text{보유 주식 수}
```

<Callout type="success" title="배당 예시">
  주간 수익 1,000,000원, 총 주식 1,000주 중 100주 보유 시: **1,000원** 배당
</Callout>

**거래 수수료: 없음.** 주식 거래는 완전 무료입니다.

## 투자 전략

### 초보 투자자

<Callout type="idea">
  꾸준히 성장하는 플레이어의 주식을 초기에 저가 매수하고, 배당 수익률이 높은 공장 중심 플레이어를
  선호하세요.
</Callout>

### 고급 투자자

<Callout type="idea">
  시장 자재 가격 상승 전에 관련 공장 주식을 선점하고, 글로벌 경제 이벤트 시 변동성이 큰 T3 공장주를
  단기 매매합니다.
</Callout>

## 주의사항

<Callout type="error" title="제재 대상 행위">
  - 자기 회사 주식 자기거래 금지 - 동일 종목 1시간 내 반복 매수·매도 제한
</Callout>

<Callout type="info">
  동일 IP 기반 차단은 Discord가 IP를 제공하지 않아 구현할 수 없습니다. 부계정 추정 시그널(신규
  계정·신규 서버 멤버 여부)도 자재 마켓 거래에서만 기록되며, 주식 거래 경로에는 아직 연결되어 있지
  않습니다. 주식 거래에서 실제로 막히는 것은 위에 적힌 자기 회사 주식 자기거래와 동일 종목 단기 반복
  거래뿐입니다.
</Callout>
