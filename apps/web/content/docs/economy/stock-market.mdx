# 주식 시장

플레이어가 직접 회사를 상장하고, 다른 플레이어의 회사 주식을 매매할 수 있습니다.

## 주식 상장 (IPO) 조건

| 조건           | 기준        |
| -------------- | ----------- |
| 레벨           | Lv.25 이상  |
| 보유 공장 수   | 5개 이상    |
| 총 자산        | 1억 원 이상 |
| 최근 30일 거래 | 10회 이상   |

상장 기준을 충족하면 `/stock ipo` 명령으로 자신의 공장을 상장할 수 있습니다.

## 글로벌 주식 (서버 간)

서버 간 주식 거래에 참여하려면 추가 조건이 필요합니다:

- 플레이어 레벨 **Lv.40 이상**
- 서버 신뢰도 **1,500pt 이상**인 서버

## IPO 가격 설정

```
기본 IPO가 = (총자산 + 최근 30일 수익 × 10) / 100
설정 가능 범위: 기본 IPO가의 30% ~ 70%
```

## 주가 변동

주가는 **1시간마다** 자동으로 갱신됩니다.

```
새 주가 = 이전 주가 × (1 + 수요 압력 + 수익 변화율 × 0.3)
```

**서킷 브레이커:** 하루 최대 ±30% 범위 제한.

## 배당

보유 주식에 대해 **매주 일요일 자정**에 배당이 지급됩니다.

```
개인 배당 = (해당 주의 수익 × 10%) / 총 주식 수 × 보유 주식 수
```

예시: 주간 수익이 1,000,000원이고 총 주식 1,000주 중 100주를 보유하면:
→ 배당 = 100,000원 × 10% / 1,000 × 100 = **1,000원**

## 거래 수수료

**없음.** 주식 거래는 수수료 없이 완전 무료입니다.

## 투자 전략

### 초보 투자자

- 꾸준히 성장하는 플레이어의 주식을 초기에 저가 매수
- 배당 수익률이 높은 공장 중심 플레이어 선호

### 고급 투자자

- 시장 자재 가격 상승 전에 관련 공장 주식 선점
- 글로벌 경제 이벤트 시 변동성이 큰 T3 공장주 단기 매매

## 주의사항

다음 행위는 탐지·제재 대상입니다:

- 자기 회사 주식 자기거래 금지
- 동일 IP/부계정 간 주식 거래 차단
- 동일 종목 1시간 내 반복 매수·매도 제한
