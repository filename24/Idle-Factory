# 플레이어 마켓

## 두 가지 마켓

| 마켓 종류   | 판매자   | 가격 방식             |
| ----------- | -------- | --------------------- |
| 글로벌 마켓 | 시스템   | 수요·공급 기반 변동가 |
| 유저 상점   | 플레이어 | 직접 설정             |

## 글로벌 마켓

### 가격 변동 원리

글로벌 마켓 가격은 **30분마다 자동 갱신**됩니다.

```
새 가격 = clamp(기준가 × (1 + 노이즈) × (1 + 수요 반영), 기준가 × 0.70, 기준가 × 2.00)
```

- **노이즈:** ±20% 랜덤 변동
- **가격 범위:** 기준가의 70% ~ 200%
- 전체 플레이어의 판매/구매량이 가격에 영향을 줍니다

### 직접 구매 가격

글로벌 마켓에서 물건을 사면 **현재 시세의 2배**를 지불합니다. 급할 때만 사용하고, 평소엔 유저 상점을 활용하세요.

## 유저 상점

레벨에 무관하게 자신이 원하는 가격으로 자재를 판매할 수 있습니다.

### 등록 한도

```
최대 등록 수 = 5 + floor(레벨 / 5)  (최대 20개)
```

| 레벨   | 최대 등록 수 |
| ------ | ------------ |
| Lv.1~4 | 5개          |
| Lv.5~9 | 6개          |
| Lv.20+ | 9개          |
| Lv.75+ | 20개 (상한)  |

### 가격 제한

글로벌 마켓 현재가의 **±50% 범위** 내에서만 설정 가능합니다.

### 수수료 (기간별 누진)

| 등록 기간 | 수수료 |
| --------- | ------ |
| 1~3일     | 3%     |
| 4~7일     | 5%     |
| 8~14일    | 8%     |
| 15~21일   | 12%    |
| 22~30일   | 18%    |

단기 등록이 수수료 면에서 유리하지만, 빠르게 팔리는 자재는 장기 등록도 고려할 수 있습니다.

### 등록 기간

최대 **30일**. 기간 내에 팔리지 않으면 자재가 창고로 반환됩니다.

## 거래 주의사항

시스템은 다음 행위를 자동으로 탐지하고 제한합니다:

- 동일 IP/부계정 간 반복 거래
- 짧은 시간 내 비정상적인 대량 거래
- 글로벌가 ±50%를 벗어난 비정상 가격 거래
- 신규 계정의 초기 마켓 접근 제한

## 거래 전략 팁

1. **30분 가격 사이클 활용:** 가격이 높을 때 판매, 낮을 때 구매
2. **T3 자재 유저 상점 판매:** 글로벌 마켓에 T3 시세가 없으므로 유저 상점이 유일한 판로
3. **수수료 최소화:** 빠르게 소진할 자재는 3일 단기 등록으로 수수료 아끼기
4. **시세 관찰:** 공급이 줄어들 것으로 예상되는 자재를 미리 매입
