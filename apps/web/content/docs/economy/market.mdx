Idle Factory의 경제는 두 가지 마켓으로 운영됩니다.

| 마켓 종류   | 판매자   | 가격 방식             |
| ----------- | -------- | --------------------- |
| 글로벌 마켓 | 시스템   | 수요·공급 기반 변동가 |
| 유저 상점   | 플레이어 | 직접 설정             |

## 글로벌 마켓

### 가격 변동 원리

글로벌 마켓 가격은 **30분마다 자동 갱신**됩니다.

```math
P_{\text{new}} = \text{clamp}\!\left(P_{\text{base}} \times (1 + \epsilon) \times (1 + \delta),\ 0.70 \cdot P_{\text{base}},\ 2.00 \cdot P_{\text{base}}\right)
```

- $$\epsilon$$: 노이즈 (±20% 랜덤 변동)
- $$\delta$$: 수요 반영값
- **가격 범위:** 기준가의 70% ~ 200%

전체 플레이어의 판매/구매량이 가격에 영향을 줍니다.

### 직접 구매 가격

<Callout type="warn">
  글로벌 마켓에서 물건을 **사면** 현재 시세의 **2배**를 지불합니다. 급할 때만 사용하고, 평소엔 유저
  상점을 활용하세요.
</Callout>

## 유저 상점

레벨에 무관하게 자신이 원하는 가격으로 자재를 판매할 수 있습니다.

### 등록 한도

현재 유저 상점에 동시 등록할 수 있는 매물 개수에는 별도 제한이 없습니다.

### 가격 제한

글로벌 마켓 현재가의 **±50% 범위** 내에서만 설정 가능합니다.

### 수수료 (기간별 누진)

| 등록 기간    | 수수료 |
| ------------ | ------ |
| 1&#126;3일   | 3%     |
| 4&#126;7일   | 5%     |
| 8&#126;14일  | 8%     |
| 15&#126;21일 | 12%    |
| 22&#126;30일 | 18%    |

<Callout type="idea">
  단기 등록이 수수료 면에서 유리하지만, 빠르게 팔리는 자재는 장기 등록도 고려할 수 있습니다.
</Callout>

### 등록 기간

최대 **30일**. 기간 내에 팔리지 않으면 자재가 창고로 반환됩니다.

## 거래 주의사항

<Callout type="error" title="자동 탐지 제재">
  시스템은 다음 행위를 자동으로 탐지하고 제한합니다:
  <ul>
    <li>동일 상대와의 반복 거래(다수 거래 시 지급 경험치 감소)</li>
    <li>글로벌가 ±50%를 벗어난 비정상 가격 거래</li>
  </ul>
</Callout>

## 거래 전략 팁

<Steps>
<Step>

#### 30분 가격 사이클 활용

가격이 높을 때 판매, 낮을 때 구매해 마진을 극대화합니다.

</Step>
<Step>

#### T3 자재 구매는 유저 상점으로

T3 완제품(자동차·전자·식품)은 글로벌 마켓에서 시세 확인과 즉시 판매는 가능하지만, 직접 구매(돈으로 즉시 사기)는 지원하지 않습니다. T3 자재를 빠르게 구해야 한다면 유저 상점을 이용하세요.

</Step>
<Step>

#### 수수료 최소화

빠르게 소진할 자재는 3일 단기 등록으로 수수료를 아낍니다.

</Step>
<Step>

#### 시세 선점

공급이 줄어들 것으로 예상되는 자재를 미리 매입합니다.

</Step>
</Steps>
