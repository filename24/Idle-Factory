Idle Factory의 모든 자재는 T1→T2→T3 계층 구조를 따릅니다.

## 자재 종류

### T1 원료

| 자재 | 생산처 | 기본 단가 |
| ---- | ------ | --------- |
| 곡물 | 농장   | 10원      |
| 광석 | 광산   | 20원      |
| 목재 | 벌목장 | 15원      |
| 원유 | 유전   | 50원      |

### T2 가공재

| 자재     | 생산처          | 기본 단가 |
| -------- | --------------- | --------- |
| 철강     | 제철소          | 50원      |
| 연료     | 정유소          | 80원      |
| 플라스틱 | 정유소 (부산물) | 60원      |
| 가공식품 | 제분소          | 25원      |
| 가구     | 가구공장        | 60원      |

### T3 완제품

| 자재      | 생산처     | 기본 단가 |
| --------- | ---------- | --------- |
| 자동차    | 자동차공장 | 500원     |
| 전자제품  | 전자공장   | 800원     |
| 완제 식품 | 식품공장   | 150원     |

### 특수 자재

<Callout type="idea" title="원료 부스터 (Raw Booster)">
  T3 공장 저확률 드롭, 글로벌 마켓·유저 상점·직거래로도 획득 가능. Lv.50 이상 공장에 적용 시 Grade
  보너스 **×1.2 배율 상승**.
</Callout>

## 화폐 흐름

| 구분     | 내용                                                              |
| -------- | ----------------------------------------------------------------- |
| **수입** | 공장 생산 수익 + 자재 판매 + 주식 배당 + 직거래                   |
| **지출** | 공장 건설·업그레이드 + 자재 구매 + 세금 + 주식 매입 + 부스터 구매 |

## 직접 구매 (Direct Buy)

시장에 원하는 자재가 없을 때 시스템에서 직접 구매할 수 있습니다.

<Callout type="warn">
  직접 구매 가격은 글로벌 마켓 가격의 **2배** (프리미엄)입니다. T1, T2만 가능하며 T3는 불가합니다.
</Callout>

**레벨별 일일 한도** (UTC 00:00 초기화):

| 레벨           | 일일 한도 |
| -------------- | --------- |
| Lv. 1&#126;5   | 100개     |
| Lv. 6&#126;15  | 500개     |
| Lv. 16&#126;30 | 2,000개   |
| Lv. 31+        | 10,000개  |

## 인플레이션 방어

게임 경제가 과열되지 않도록 다음 메커니즘이 작동합니다:

| 메커니즘             | 설명                                 |
| -------------------- | ------------------------------------ |
| **세금 징수**        | 판매 수익의 5~20% (누진 구조)        |
| **유지비**           | 운영 중인 공장에 소액 유지 비용 부과 |
| **직접 구매 마크업** | 시장가 2배 → 시스템 유입 자금 증가   |
| **부스터 구매 비용** | 경제 순환에서 돈을 소각              |

<Callout type="success" title="경제 균형">
  이 시스템 덕분에 글로벌 마켓 가격은 장기적으로 균형 상태를 유지합니다.
</Callout>
