**Idle Factory**는 Discord 봇을 통해 플레이하는 방치형 공장 경영 게임입니다. 슬래시 커맨드(`/`)만으로 공장을 짓고, 자재를 생산하고, 글로벌 시장에서 거래하며 산업 제국을 키워나갑니다.

## 핵심 특징

### 방치형 자동 생산

한 번 공장을 지으면 접속하지 않아도 생산이 계속됩니다. `/수확` 명령어로 언제든 쌓인 자재를 수확할 수 있습니다.

<Callout type="warn" title="창고 주의">
  창고가 꽉 차면 모든 공장 생산이 멈춥니다. 주기적으로 `/수확` 후 자재를 판매하거나 창고를
  업그레이드하세요.
</Callout>

### 3단계 생산 사슬

공장은 **T1 원료 채취 → T2 1차 가공 → T3 완제품**의 계층 구조로 이루어져 있습니다. T3 공장은 T2 가공재를 원료로 사용하므로, 수직 통합 전략이 수익 극대화의 핵심입니다.

### 글로벌 실시간 경제

모든 Discord 서버가 하나의 글로벌 마켓으로 연결됩니다. 자재 공급이 많아지면 가격이 내려가고, 희소해지면 오릅니다.

<Callout type="idea" title="투자 전략">
  시장을 읽는 플레이어가 더 많이 벌 수 있습니다. 특정 자재 가격이 오를 타이밍에 생산을 집중해보세요.
</Callout>

### 레벨 & 성장

거래하고, 생산하고, 공장을 짓는 모든 행동에서 경험치를 얻습니다. 레벨이 오를수록 더 많은 기능이 해금됩니다.

## 주요 커맨드

| 커맨드    | 설명                     |
| --------- | ------------------------ |
| `/토지`   | 내 토지와 공장 배치 확인 |
| `/공장`   | 공장 건설·업그레이드     |
| `/수확`   | 생산된 자재 수확         |
| `/창고`   | 창고 현황 확인           |
| `/시장`   | 글로벌 마켓 가격 조회    |
| `/프로필` | 내 플레이어 정보 확인    |

## 게임 시작 전 알아두기

<Callout type="info">
  - **서버 어드민이 봇을 먼저 초대해야** 합니다 - 모든 플레이어의 자산(현금·창고·공장·주식)은
  **서버와 무관한 하나의 글로벌 계정**에 귀속됩니다 - T2·T3 공장을 짓기 전에 **레벨 조건**을
  확인하세요 (T2: Lv.5, T3: Lv.10)
</Callout>
