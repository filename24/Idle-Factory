title: 시작하는 방법

---

새 플레이어는 **1,000원 시드머니**와 **4×4 토지** (16슬롯)를 가지고 시작합니다. 초반 튜토리얼 퀘스트를 완료하면 최대 **6,000원**까지 자금을 모을 수 있습니다.

<Callout type="info" title="핵심 루프">
  공장 건설 → 자동 생산 → `/수확` → 자재 판매 또는 업그레이드 → 재투자
</Callout>

## 단계별 가이드

<Steps>
<Step>

### 토지 확인

```
/토지
```

처음 받은 4×4 토지를 확인합니다. 슬롯 중 일부는 특수 지형(🌱 농지, 🪨 광석 등)으로 표시됩니다.

<Callout type="success" title="특수 슬롯 보너스">
  해당 슬롯에 맞는 공장을 지으면 **+20~30% 생산 보너스**를 받습니다. 배치 전 슬롯을 꼭 확인하세요.
</Callout>

</Step>
<Step>

### T1 공장 건설

T1 공장은 **1,000원**으로 지을 수 있습니다. 초보자에게 추천하는 공장:

| 공장      | 생산물 | 기본가  | Grade 1 수익 |
| --------- | ------ | ------- | ------------ |
| 🌾 농장   | 곡물   | 10원/개 | 300원/틱     |
| ⛏️ 광산   | 광석   | 20원/개 | 300원/틱     |
| 🪵 벌목장 | 목재   | 15원/개 | 375원/틱     |
| 🛢️ 유전   | 원유   | 50원/개 | 400원/틱     |

<Callout type="idea">
  광산이나 유전은 단가가 높아 초반 수익률이 좋습니다. 특수 슬롯이 있다면 그에 맞는 공장을
  배치하세요.
</Callout>

</Step>
<Step>

### 자재 수확

생산은 **10분 = 1틱** 주기로 자동 진행됩니다. 쌓인 자재를 가져오려면:

```
/수확
```

<Callout type="warn">
  창고가 꽉 차면 모든 공장이 멈춥니다. 주기적으로 `/수확` 하거나 창고를 업그레이드하세요.
</Callout>

</Step>
<Step>

### 자재 판매

수확한 자재는 글로벌 마켓에서 판매할 수 있습니다:

```
/시장 판매
```

판매 수익은 즉시 지갑에 들어옵니다.

</Step>
<Step>

### 공장 업그레이드

자금이 쌓이면 공장을 업그레이드하세요. **Grade가 1 오를 때마다 생산량이 1.5배**로 늘어납니다.

```
/공장 업그레이드
```

**업그레이드 비용** (Grade $$N \to N+1$$):

```math
\text{비용} = \text{건설비} \times 3^{N}
```

| 업그레이드 | 비용     |
| ---------- | -------- |
| Grade 1→2  | 3,000원  |
| Grade 2→3  | 9,000원  |
| Grade 3→4  | 27,000원 |

</Step>
</Steps>
