# 튜토리얼 퀘스트

신규 플레이어는 5개의 튜토리얼 퀘스트를 순서대로 진행합니다. 모두 완료하면 **초기 지급 1,000원 + 보상 5,000원 = 총 6,000원**으로 게임을 시작할 수 있습니다.

## 퀘스트 체인

### Quest 1 — 첫 번째 공장 건설

**목표:** T1 공장 1개 건설  
**완료 조건:** `/land build` 성공  
**보상:** +1,000원

처음 받은 1,000원으로 바로 T1 공장을 지을 수 있습니다. 특수 슬롯이 있다면 그에 맞는 공장을 선택하면 생산 보너스를 받습니다.

---

### Quest 2 — 첫 번째 수확

**목표:** 공장에서 자재 수확  
**완료 조건:** `/harvest` 성공  
**보상:** +500원

공장을 지은 후 10분이 지나면 자재가 쌓입니다. `/harvest`로 창고에 옮기세요.

---

### Quest 3 — 마켓에서 자재 판매

**목표:** 글로벌 마켓에서 자재 1개 이상 판매  
**완료 조건:** 판매 성공  
**보상:** +500원

수확한 자재를 `/market sell`로 판매해 보세요. 판매 수익으로 다음 공장을 준비합니다.

---

### Quest 4 — 공장 업그레이드

**목표:** 공장 Grade 1→2 업그레이드  
**완료 조건:** `/factory upgrade` 성공  
**보상:** +2,000원

업그레이드 비용은 **3,000원**입니다. Quest 1~3 보상과 판매 수익을 합치면 충분합니다. Grade 2로 올리면 생산량이 **1.5배**로 늘어납니다.

---

### Quest 5 — 두 번째 공장 건설

**목표:** T1 공장 2개 보유  
**완료 조건:** T1 공장 2개 이상 동시 보유  
**보상:** +1,000원

Quest 4 보상으로 두 번째 공장을 지으세요. 이제 두 종류의 자재를 동시에 생산할 수 있습니다.

---

## 보상 요약

| 퀘스트                    | 보상        |
| ------------------------- | ----------- |
| 1 - 첫 공장 건설          | +1,000원    |
| 2 - 첫 수확               | +500원      |
| 3 - 마켓 판매             | +500원      |
| 4 - 공장 업그레이드       | +2,000원    |
| 5 - 두 번째 공장          | +1,000원    |
| **합계 (초기 자금 포함)** | **6,000원** |

## 튜토리얼 완료 후

퀘스트 완료 후 자연스럽게 다음 목표를 설정하세요:

1. **창고 업그레이드** — 기본 3,000슬롯은 공장이 늘수록 금방 차 오릅니다
2. **T2 공장 준비** — Lv.5 도달 후 제철소·제분소 등 가공 공장 건설
3. **유저 상점 개설** — Lv.5 이상에서 직접 판매로 더 높은 마진 확보

더 자세한 내용은 [공장 건설](/docs/facilities/factories) 가이드를 참고하세요.
