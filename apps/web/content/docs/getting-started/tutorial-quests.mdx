---

신규 플레이어는 5개의 튜토리얼 퀘스트를 순서대로 진행합니다.

<Callout type="success" title="총 보상">
  초기 지급 1,000원 + 퀘스트 보상 5,000원 = **총 6,000원**으로 게임을 시작할 수 있습니다.
</Callout>

## 퀘스트 체인

<Steps>
<Step>

### Quest 1 — 첫 번째 공장 건설

**목표:** T1 공장 1개 건설 | **보상:** +1,000원

```
/토지 건설
```

처음 받은 1,000원으로 바로 T1 공장을 지을 수 있습니다. 특수 슬롯이 있다면 그에 맞는 공장을 선택하면 생산 보너스를 받습니다.

</Step>
<Step>

### Quest 2 — 첫 번째 수확

**목표:** 공장에서 자재 수확 | **보상:** +500원

```
/수확
```

공장을 지은 후 10분이 지나면 자재가 쌓입니다. `/수확`으로 창고에 옮기세요.

</Step>
<Step>

### Quest 3 — 마켓에서 자재 판매

**목표:** 글로벌 마켓에서 자재 1개 이상 판매 | **보상:** +500원

```
/시장 판매
```

수확한 자재를 판매해 보세요. 판매 수익으로 다음 공장을 준비합니다.

</Step>
<Step>

### Quest 4 — 공장 업그레이드

**목표:** 공장 Grade 1→2 업그레이드 | **보상:** +2,000원

```
/공장 업그레이드
```

업그레이드 비용은 **3,000원**입니다. Quest 1~3 보상과 판매 수익을 합치면 충분합니다.

<Callout type="success">Grade 2로 올리면 생산량이 **1.5배**로 늘어납니다.</Callout>

</Step>
<Step>

### Quest 5 — 두 번째 공장 건설

**목표:** T1 공장 2개 보유 | **보상:** +1,000원

Quest 4 보상으로 두 번째 공장을 지으세요. 이제 두 종류의 자재를 동시에 생산할 수 있습니다.

</Step>
</Steps>

## 보상 요약

| 퀘스트                    | 보상        |
| ------------------------- | ----------- |
| 1 - 첫 공장 건설          | +1,000원    |
| 2 - 첫 수확               | +500원      |
| 3 - 마켓 판매             | +500원      |
| 4 - 공장 업그레이드       | +2,000원    |
| 5 - 두 번째 공장          | +1,000원    |
| **합계 (초기 자금 포함)** | **6,000원** |
