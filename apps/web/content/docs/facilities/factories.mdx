공장은 Idle Factory의 핵심입니다. T1→T2→T3의 3단계 티어 구조로 이루어져 있으며, 높은 티어일수록 고부가가치 자재를 생산합니다.

## 생산 사이클

**1틱 = 10분.** 공장은 10분마다 자동으로 자재를 생산합니다. 생산된 자재는 창고에 쌓이며, `/수확` 명령으로 한 번에 수확합니다.

<Callout type="warn">
  창고가 꽉 차면 모든 공장 생산이 일시 정지됩니다. 자재를 판매하거나 창고를 업그레이드하면
  재개됩니다.
</Callout>

## T1 — 원료 채취 공장

원료를 직접 채취하는 기초 공장. 건설 비용 **1,000원**, 크기 **1×1 슬롯**.

| 공장      | 생산물 | Grade 1 생산량/틱 | 기본 단가 | Grade 1 수익/틱 |
| --------- | ------ | ----------------- | --------- | --------------- |
| 🌾 농장   | 곡물   | 30개              | 10원      | 300원           |
| ⛏️ 광산   | 광석   | 15개              | 20원      | 300원           |
| 🪵 벌목장 | 목재   | 25개              | 15원      | 375원           |
| 🛢️ 유전   | 원유   | 8개               | 50원      | 400원           |

## T2 — 1차 가공 공장

T1 원료를 가공하는 공장. 건설 비용 **10,000원 + T1 원료 100개**, 크기 **1×1 슬롯**.

<Callout type="info" title="건설 조건">
  Lv.5 이상, 해당 T1 원료 100개 보유 시 건설 가능합니다.
</Callout>

| 공장        | 레시피   | 생산물              | Grade 1 생산량/틱 |
| ----------- | -------- | ------------------- | ----------------- |
| 🏭 제철소   | 광석 3 → | 철강 5              | 5개               |
| 🔧 정유소   | 원유 2 → | 연료 2 + 플라스틱 1 | 3개               |
| 🌾 제분소   | 곡물 5 → | 가공식품 8          | 8개               |
| 🪑 가구공장 | 목재 4 → | 가구 6              | 6개               |

## T3 — 완제품 공장

최고 부가가치의 완제품 생산. 건설 비용 **100,000원 + T2 자재 50개**, 크기 **2×2 슬롯**.

<Callout type="info" title="건설 조건">
  Lv.10 이상, 해당 T2 자재 50개 보유 시 건설 가능합니다.
</Callout>

| 공장           | 레시피                | 생산물      | 기본 단가 |
| -------------- | --------------------- | ----------- | --------- |
| 🚗 자동차 공장 | 철강 3 + 플라스틱 2 → | 자동차 1    | 500원     |
| 💻 전자 공장   | 철강 1 + 플라스틱 3 → | 전자제품 1  | 800원     |
| 🍱 식품 공장   | 가공식품 4 + 연료 1 → | 완제 식품 2 | 150원     |

## Grade 업그레이드

Grade를 올리면 **생산량이 1.5배씩 증가**합니다.

```math
\text{생산량}(G) = \text{기본 생산량} \times 1.5^{G-1}
```

Grade 10 공장은 기본의 **38.44배** 생산합니다.

### 업그레이드 비용

**원화 비용:** 건설비 × 3^N (N = 현재 Grade)

```math
\text{원화 비용}(N) = \text{건설비} \times 3^{N}
```

| T1 농장 기준          | 원화 비용           |
| --------------------- | ------------------- |
| Grade 1→2             | 3,000원             |
| Grade 2→3             | 9,000원             |
| Grade 3→4             | 27,000원            |
| Grade 9→10            | 19,683,000원        |
| **Grade 10까지 누적** | **약 29,524,000원** |

**자재 비용:** Base × 2^(N-1) (T1: base 20개, T2: base 10개, T3: base 5개)

| Grade | T1 자재 비용 |
| ----- | ------------ |
| 1→2   | 20개         |
| 2→3   | 40개         |
| 3→4   | 80개         |
| 4→5   | 160개        |

## 업그레이드 부스터

Grade 3, 5, 7, 10 달성 시 각각 부스터를 1개 선택합니다.

<Callout type="error" title="선택 불가 변경">
  한번 선택하면 **영구히 변경 불가**합니다. 신중하게 결정하세요.
</Callout>

| 부스터       | 효과                               |
| ------------ | ---------------------------------- |
| 💾 재료 절약 | T2/T3 원료 소모 -20%               |
| 💎 희귀 재료 | 원료 부스터 드롭 (T1 0.5% / T2 1%) |
| ⚡ 속도      | 생산량/틱 +15% (모든 티어)         |
| 💰 수익      | 공장 수익 +10% (모든 티어)         |

## 원료 부족 시 동작

원료 재고가 없어 T2/T3 공장이 생산하지 못할 때의 동작 방식을 설정할 수 있습니다:

| 모드               | 설명                           |
| ------------------ | ------------------------------ |
| **A. 대기 (기본)** | 원료가 생길 때까지 생산 중단   |
| **B. 자동 구매**   | 시장에서 자동으로 원료 구매    |
| **C. 부분 생산**   | 가용 원료 한도에서 최대한 생산 |

<Callout type="warn" title="현재는 세 모드 모두 '대기'로 동작합니다">
  설정 자체는 저장되지만, 아직 **자동 구매**와 **부분 생산**은 구현되지 않았습니다. 어느 모드를
  고르든 원료가 부족하면 생산이 멈춥니다. 두 모드는 이후 업데이트에서 실제로 동작하게 됩니다.
</Callout>
