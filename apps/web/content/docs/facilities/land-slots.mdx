# 토지 & 슬롯

토지는 공장을 배치하는 격자판입니다. 모든 플레이어는 기본 **4×4 토지 (16슬롯)**에서 시작합니다.

## 공장 슬롯 크기

| 티어    | 슬롯 크기 |
| ------- | --------- |
| T1 공장 | 1×1       |
| T2 공장 | 1×1       |
| T3 공장 | 2×2       |

T3 공장은 4개의 슬롯을 차지하므로 배치 계획이 중요합니다.

## 특수 슬롯

토지 슬롯의 약 **15%**가 특수 지형으로 생성됩니다. 특수 슬롯에 해당 공장을 배치하면 생산 보너스를 받습니다.

| 특수 슬롯    | 어울리는 공장    | 보너스 |
| ------------ | ---------------- | ------ |
| 🌱 비옥한 땅 | 농장             | +20%   |
| 🪨 광석 지대 | 광산             | +20%   |
| 🌳 숲        | 벌목장           | +20%   |
| 🛢️ 유전 지대 | 유전             | +30%   |
| 💧 수원      | 인접 농장·제분소 | +10%   |

> 특수 슬롯은 랜덤으로 배정되며 **변경 불가**입니다. 토지 구매 전 슬롯 배치를 미리 확인하세요.

## 인접 시너지

특정 공장을 인접하게 배치하면 추가 보너스를 받습니다. 최대 **+30%까지 중첩** 가능합니다.

| 조합                | 효과               |
| ------------------- | ------------------ |
| 광산 ↔ 제철소       | 제철소 생산 +10%   |
| 유전 ↔ 정유소       | 정유소 생산 +10%   |
| 농장 ↔ 제분소       | 제분소 생산 +10%   |
| 벌목장 ↔ 가구공장   | 가구공장 생산 +10% |
| 제철소 ↔ 자동차공장 | 자동차 생산 +5%    |
| 정유소 ↔ 자동차공장 | 자동차 생산 +5%    |
| 제분소 ↔ 식품공장   | 식품 생산 +5%      |
| 💧수원 ↔ 농장       | 농장 생산 +10%     |

**예시:** 제철소 옆에 광산과 자동차공장을 모두 붙이면 제철소 +10%, 자동차공장 +5% × 2 = +10% 동시 적용.

## 공장 이동 & 철거

| 작업                  | 비용                 |
| --------------------- | -------------------- |
| 같은 토지 내 이동     | 건설 비용의 25%      |
| 철거 (자재 환불 없음) | 건설 비용의 50% 환불 |

## 토지 확장

Phase 1에서는 1개 토지(4×4)만 사용합니다. Phase 2 이후 추가 토지 구매 가능:

| 토지              | 구매 비용       |
| ----------------- | --------------- |
| 2번째 토지        | 1,000,000원     |
| 3번째 토지        | 10,000,000원    |
| 4번째 토지        | 100,000,000원   |
| 5번째 토지 (최대) | 1,000,000,000원 |

각 토지는 독립된 인접 시너지 그룹입니다. 서로 다른 토지의 공장 간에는 시너지가 적용되지 않습니다.

## 효율적인 배치 전략

1. **특수 슬롯 우선:** 처음에 슬롯 종류를 파악하고 맞는 공장 배치
2. **인접 시너지 계획:** T2/T3 공장은 원료 T1 공장과 인접하게 배치
3. **T3 위치 선점:** 2×2 공장은 코너보다 중앙에 배치해야 이후 확장이 용이
4. **창고 위치 고정:** 창고는 이동·철거 불가이므로 초반 배치가 중요
