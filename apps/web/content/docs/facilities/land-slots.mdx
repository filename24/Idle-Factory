토지는 공장을 배치하는 격자판입니다. 토지 한 필지는 **4×4 (16슬롯)** 크기지만, 처음부터 전부 쓸 수 있는 것은 아닙니다. 모든 플레이어는 **3×3 (9슬롯)**이 열린 상태로 시작하고, 나머지 7칸은 잠겨 있습니다. 잠긴 슬롯은 아래 [슬롯 확장](#슬롯-확장)으로 하나씩 해금합니다.

이는 새로 구매한 토지도 마찬가지입니다 — 어느 토지든 3×3으로 시작합니다.

## 공장 슬롯 크기

| 티어    | 슬롯 크기 |
| ------- | --------- |
| T1 공장 | 1×1       |
| T2 공장 | 1×1       |
| T3 공장 | 2×2       |

<Callout type="warn">
  T3 공장은 4개의 슬롯을 차지하므로 배치 계획이 중요합니다. 코너보다 중앙 배치를 권장합니다.
</Callout>

## 특수 슬롯

토지 슬롯의 약 **15%**가 특수 지형으로 생성됩니다. 특수 슬롯에 해당 공장을 배치하면 생산 보너스를 받습니다.

| 특수 슬롯    | 어울리는 공장    | 보너스 |
| ------------ | ---------------- | ------ |
| 🌱 비옥한 땅 | 농장             | +20%   |
| 🪨 광석 지대 | 광산             | +20%   |
| 🌳 숲        | 벌목장           | +20%   |
| 🛢️ 유전 지대 | 유전             | +30%   |
| 💧 수원      | 인접 농장·제분소 | +10%   |

<Callout type="error" title="변경 불가">
  특수 슬롯은 랜덤으로 배정되며 **변경 불가**입니다. 토지 구매 전 슬롯 배치를 미리 확인하세요.
</Callout>

## 인접 시너지

특정 공장을 인접하게 배치하면 추가 보너스를 받습니다. 최대 **+30%까지 중첩** 가능합니다.

| 조합                | 효과               |
| ------------------- | ------------------ |
| 광산 ↔ 제철소       | 제철소 생산 +10%   |
| 유전 ↔ 정유소       | 정유소 생산 +10%   |
| 농장 ↔ 제분소       | 제분소 생산 +10%   |
| 벌목장 ↔ 가구공장   | 가구공장 생산 +10% |
| 제철소 ↔ 자동차공장 | 자동차 생산 +5%    |
| 정유소 ↔ 자동차공장 | 자동차 생산 +5%    |
| 제분소 ↔ 식품공장   | 식품 생산 +5%      |
| 💧수원 ↔ 농장       | 농장 생산 +10%     |

<Callout type="idea" title="시너지 예시">
  제철소 옆에 광산과 자동차공장을 모두 붙이면 제철소 +10%, 자동차공장 +5% × 2 = +10% 동시
  적용됩니다.
</Callout>

## 공장 이동 & 철거

| 작업                  | 비용                 |
| --------------------- | -------------------- |
| 같은 토지 내 이동     | 건설 비용의 25%      |
| 철거 (자재 환불 없음) | 건설 비용의 50% 환불 |

## 슬롯 확장

토지는 3×3(9슬롯)으로 시작하므로, 나머지 7칸은 하나씩 구매해 해금해야 합니다.

비용은 **토지 번호**와 **그 토지에서 몇 번째로 확장하는지**에 따라 정해집니다.

```
비용 = 5,000원 × 10^(토지번호-1) × 2^(확장순서-1)
```

같은 토지 안에서는 확장할수록 비용이 두 배씩 오르고, 뒤쪽 토지일수록 시작 단가가 10배씩 높습니다.

| 확장 순서 | 토지 1번  | 토지 2번            | 토지 3번             |
| --------- | --------- | ------------------- | -------------------- |
| 1번째     | 5,000원   | 50,000원 (Lv.5)     | 500,000원 (Lv.20)    |
| 2번째     | 10,000원  | 100,000원 (Lv.7)    | 1,000,000원 (Lv.22)  |
| 3번째     | 20,000원  | 200,000원 (Lv.10)   | 2,000,000원 (Lv.25)  |
| 4번째     | 40,000원  | 400,000원 (Lv.12)   | 4,000,000원 (Lv.27)  |
| 5번째     | 80,000원  | 800,000원 (Lv.15)   | 8,000,000원 (Lv.30)  |
| 6번째     | 160,000원 | 1,600,000원 (Lv.17) | 16,000,000원 (Lv.33) |
| 7번째     | 320,000원 | 3,200,000원 (Lv.20) | 32,000,000원 (Lv.35) |

<Callout type="info">
  **첫 번째 토지는 레벨 제한이 없습니다.** 두 번째 토지부터 확장 순서마다 최소 레벨이 붙습니다.
</Callout>

## 토지 구매

최대 5개 토지를 보유할 수 있습니다. 구매 비용은 번호가 올라갈수록 10배씩 오릅니다.

| 토지              | 구매 비용       |
| ----------------- | --------------- |
| 2번째 토지        | 1,000,000원     |
| 3번째 토지        | 10,000,000원    |
| 4번째 토지        | 100,000,000원   |
| 5번째 토지 (최대) | 1,000,000,000원 |

새로 구매한 토지도 3×3으로 시작하므로, 슬롯 확장 비용이 별도로 듭니다.

<Callout type="info">
  각 토지는 독립된 인접 시너지 그룹입니다. 서로 다른 토지의 공장 간에는 시너지가 적용되지 않습니다.
</Callout>

## 효율적인 배치 전략

<Steps>
<Step>

#### 특수 슬롯 파악

처음에 `/토지`로 슬롯 종류를 파악하고 맞는 공장을 배치합니다.

</Step>
<Step>

#### T3 위치 선점

2×2 공장은 코너보다 중앙에 배치해야 이후 확장이 용이합니다.

</Step>
<Step>

#### 인접 시너지 계획

T2/T3 공장은 원료 T1 공장과 인접하게 배치해 시너지를 챙깁니다.

</Step>
<Step>

#### 창고는 배치 대상 아님

창고는 유저당 1개뿐인 전역 시설로 토지 슬롯 좌표를 갖지 않으므로, 이동·철거 계획에서 고려할 필요가 없습니다.

</Step>
</Steps>
