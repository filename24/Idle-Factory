# 창고

창고는 공장에서 생산된 자재를 보관하는 시설입니다. 모든 플레이어는 토지에 **Grade 1 창고 (3,000슬롯)**를 가지고 시작합니다.

## 창고 기본 규칙

- 창고는 토지의 **1슬롯**을 차지합니다
- **이동·철거 불가** — 초기 배치 위치가 영구적입니다
- 자재 1개 = 창고 슬롯 1개 (종류 무관)
- **창고가 꽉 차면 모든 공장 생산이 즉시 중단**됩니다

## 등급별 수용량

| Grade    | 수용량          |
| -------- | --------------- |
| 1 (기본) | 3,000 슬롯      |
| 2        | 9,000 슬롯      |
| 3        | 27,000 슬롯     |
| 4        | 81,000 슬롯     |
| 5        | 243,000 슬롯    |
| 6        | 729,000 슬롯    |
| 7        | 2,187,000 슬롯  |
| 8        | 6,561,000 슬롯  |
| 9        | 19,683,000 슬롯 |
| 10       | 59,049,000 슬롯 |

**공식:** Grade N 수용량 = 3,000 × 3^(N-1)

## 업그레이드 비용 (예시)

| Grade | 원화      | 필요 자재  |
| ----- | --------- | ---------- |
| 1→2   | 5,000원   | 목재 100개 |
| 2→3   | 15,000원  | 목재 300개 |
| 4→5   | 150,000원 | 철강 200개 |

## 창고 용량 계산 예시

Grade 5 공장이 늘어날수록 시간당 생산량도 크게 늘어납니다:

| 구성                  | 시간당 생산량    |
| --------------------- | ---------------- |
| 농장 Grade 5 (152/틱) | 912개/시간       |
| 광산 Grade 5 (76/틱)  | 456개/시간       |
| **합계**              | **1,368개/시간** |

이 경우 Grade 2 창고 (9,000슬롯)로 **6.5시간**을 버팁니다. 공장 Grade가 올라갈수록 더 큰 창고가 필요해집니다.

## 운영 팁

### 언제 업그레이드해야 하나?

- 하루 1~2회 접속하는 경우: **24~48시간 분량**의 생산량을 보관할 수 있는 Grade를 목표
- 공장 Grade를 올릴 때마다 창고 업그레이드도 함께 계획

### 창고가 꽉 찼을 때

1. `/harvest` → 창고 현황 확인
2. `/market sell` → 과잉 자재 판매
3. 여유 공간이 생기면 생산 자동 재개

> **중요:** 창고가 꽉 차서 생산이 멈춰도 자재는 **유실되지 않습니다**. 공간만 확보하면 바로 재개됩니다.
