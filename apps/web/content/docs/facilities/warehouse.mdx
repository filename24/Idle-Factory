창고는 공장에서 생산된 자재를 보관하는 시설입니다. 모든 플레이어는 토지에 **Grade 1 창고 (3,000슬롯)**를 가지고 시작합니다.

## 창고 기본 규칙

- 창고는 토지의 슬롯 시스템과 무관하게 유저당 하나 지급되며, 공장을 배치할 수 있는 슬롯 수에 영향을 주지 않습니다
- **이동·철거 불가** — 초기 배치 위치가 영구적입니다
- 자재마다 차지하는 슬롯 수(부피 계수)가 다릅니다 — 원유 1개는 5슬롯, 광석 1개는 2슬롯, 그 외 대부분의 자재는 1슬롯을 차지합니다

<Callout type="warn" title="창고 포화 주의">
  **창고가 꽉 차면 모든 공장 생산이 즉시 중단**됩니다. 정기적으로 `/수확` 후 자재를 판매하세요.
</Callout>

## 등급별 수용량

수용량은 Grade마다 3배씩 증가합니다:

```math
\text{수용량}(N) = 3{,}000 \times 3^{N-1}
```

| Grade    | 수용량          |
| -------- | --------------- |
| 1 (기본) | 3,000 슬롯      |
| 2        | 9,000 슬롯      |
| 3        | 27,000 슬롯     |
| 4        | 81,000 슬롯     |
| 5        | 243,000 슬롯    |
| 6        | 729,000 슬롯    |
| 7        | 2,187,000 슬롯  |
| 8        | 6,561,000 슬롯  |
| 9        | 19,683,000 슬롯 |
| 10       | 59,049,000 슬롯 |

## 업그레이드 비용 (예시)

| Grade | 원화      | 필요 자재  |
| ----- | --------- | ---------- |
| 1→2   | 5,000원   | 목재 100개 |
| 2→3   | 15,000원  | 목재 300개 |
| 4→5   | 150,000원 | 철강 200개 |

## 창고 용량 계획 예시

Grade 5 공장이 늘어날수록 시간당 생산량도 크게 늘어납니다:

| 구성                  | 시간당 생산량    |
| --------------------- | ---------------- |
| 농장 Grade 5 (152/틱) | 912개/시간       |
| 광산 Grade 5 (76/틱)  | 456개/시간       |
| **합계**              | **1,368개/시간** |

<Callout type="info">
  광석은 부피 계수가 2라 자재 개수보다 슬롯을 더 차지합니다 — 광산의 456개/시간은 슬롯 912개/시간에
  해당하며, 합계 슬롯 소모는 1,824개/시간입니다. 이 경우 Grade 2 창고 (9,000슬롯)로 **약 4.9시간**을
  버팁니다. 공장 Grade가 올라갈수록 더 큰 창고가 필요해집니다.
</Callout>

## 운영 전략

### 언제 업그레이드해야 하나?

- 하루 1&#126;2회 접속하는 경우: **24&#126;48시간 분량**의 생산량을 보관할 수 있는 Grade를 목표
- 공장 Grade를 올릴 때마다 창고 업그레이드도 함께 계획

### 창고가 꽉 찼을 때

<Steps>
<Step>

#### `/수확` → 창고 현황 확인

현재 몇 슬롯이 남았는지 확인합니다.

</Step>
<Step>

#### `/시장 판매` → 과잉 자재 판매

가격이 높은 자재부터 우선 판매합니다.

</Step>
<Step>

#### 생산 자동 재개

여유 공간이 생기면 모든 공장이 자동으로 재개됩니다.

</Step>
</Steps>

<Callout type="success" title="자재 보존">
  창고가 꽉 차서 생산이 멈춰도 자재는 **유실되지 않습니다**. 공간만 확보하면 바로 재개됩니다.
</Callout>
