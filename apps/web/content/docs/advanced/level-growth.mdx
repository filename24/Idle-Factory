# 레벨 & 성장

레벨은 게임 내 모든 활동으로 오르며, 높은 레벨에서 더 많은 기능이 해금됩니다.

## 경험치 획득

| 활동               | 경험치                                  |
| ------------------ | --------------------------------------- |
| 생산 틱 (10분마다) | +5 XP                                   |
| 마켓 판매          | +20 XP                                  |
| 직거래             | +15 XP                                  |
| 주식 수익 실현     | +10 XP                                  |
| 공장 건설          | 건설비 × 0.001 (상한 1,000 XP)          |
| 공장 업그레이드    | 업그레이드 비용 × 0.001 (상한 1,000 XP) |

**일일 획득 한도 없음** — 활발하게 플레이할수록 빠르게 성장합니다.

## 레벨업 공식

```
레벨 N → N+1에 필요한 누적 XP = 100 × N^2.2
```

| 레벨 | 해당 레벨까지 누적 XP |
| ---- | --------------------- |
| 2    | 100                   |
| 3    | ~559                  |
| 6    | ~8,000                |
| 11   | ~57,000               |
| 26   | ~1,200,000            |
| 50   | ~25,000,000           |

초반엔 빠르게 오르지만 고레벨로 갈수록 필요 XP가 급격히 늘어납니다.

## 레벨별 해금 기능

| 레벨      | 해금 내용                                       |
| --------- | ----------------------------------------------- |
| **Lv.1**  | T1 공장 건설 (농장·광산·벌목장·유전)            |
| **Lv.5**  | T2 공장 건설 (제철소·정유소·제분소·가구공장)    |
| **Lv.10** | T3 공장 건설 + 서버 주식 거래 참여              |
| **Lv.25** | 주식 상장 (IPO) 자격                            |
| **Lv.40** | 글로벌 주식 참여 (서버 신뢰도 1,500+ 조건 필요) |
| **Lv.50** | 원료 부스터 사용 가능                           |

## 효율적인 성장 전략

### 초반 (Lv.1~10)

- 튜토리얼 퀘스트로 공장 건설 XP 확보
- 매일 자재를 마켓에 판매 (+20 XP씩)
- Lv.5 달성 후 T2 공장 건설로 큰 XP 획득

### 중반 (Lv.10~25)

- T3 공장 건설 — 비용이 크므로 XP도 많음 (최대 1,000 XP)
- 주식 거래 수익 실현으로 꾸준한 XP 보충
- 직거래를 통한 XP 효율적 확보

### 고급 (Lv.25+)

- 공장 업그레이드 고단계 진행 — 업그레이드 비용이 크므로 대량 XP
- 글로벌 마켓 대량 거래 + 주식 투자

## XP 어뷰징 방지

다음 상황에서 XP가 감소하거나 지급되지 않습니다:

- 동일 상대방과의 반복 거래 → XP 점차 감소
- 짧은 시간 내 대량 거래 → XP = 0
- 동일 IP/부계정 간 거래 → XP 미지급
- 글로벌 시세 ±50% 벗어난 비정상 가격 거래 → 차단
