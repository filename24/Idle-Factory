# 서버 & 글로벌 시스템

Idle Factory에 참여한 모든 Discord 서버는 하나의 글로벌 경제권으로 연결됩니다. 서버의 활성도가 플레이어 경험에 직접 영향을 줍니다.

## 서버 신뢰도

각 서버는 **0~2,000pt** 범위의 신뢰도를 가집니다. 기본값은 **1,000pt**.

| 신뢰도 구간 | 효과                                                   |
| ----------- | ------------------------------------------------------ |
| 0~300       | 대부분 기능 제한, 긴급 지원금 최대 100만원             |
| 300~700     | 일부 기능 제한 (유저 상점 등록 불가)                   |
| 700~1,000   | 정상 운영                                              |
| 1,000~1,500 | 공장 최대 Grade +1, 경험치 +10%                        |
| 1,500 이상  | 글로벌 주식 참여 가능, 공장 최대 Grade +2, 경험치 +20% |

### 신뢰도 변화

**매주 일요일 자정**에 자동 조정됩니다:

```
주간 변화량 = floor(주간 활성 유저 수 × 0.5) - 10
```

서버에 활성 유저가 많을수록 신뢰도가 오르고, 적으면 내려갑니다.

## 세금 시스템

판매 수익에 대해 **누진 세율**이 적용됩니다. (생산 틱 수익은 과세 제외)

| 주간 판매 수익    | 세율 |
| ----------------- | ---- |
| 0 ~ 100만원       | 5%   |
| 100만 ~ 1,000만원 | 10%  |
| 1,000만 ~ 1억원   | 15%  |
| 1억원 이상        | 20%  |

서버 어드민이 추가 세율을 설정할 수 있습니다 (+0~20%p, 최대 40% 유지).

**세금 정산:** 매주 일요일 자정

### 세금 분배

징수된 세금의 절반은 글로벌 재분배 풀로, 나머지 절반은 서버 운영 보상으로 사용됩니다.

## 비활성 서버 자산 재분배

서버가 30일 이상 비활성화되면:

| 기간           | 처리                       |
| -------------- | -------------------------- |
| 30일 이내 복귀 | 자산 전액 복원             |
| 30일 초과      | 자산 전부 재분배 풀로 이동 |

**재분배 시점:** 매월 1일 자정

**분배 대상:** 신뢰도 300pt 이상인 활성 서버

- 서버 금고 70%
- 활성 유저 지갑 30%

## 글로벌 경제 참여

서버 신뢰도가 높을수록 더 많은 혜택을 누릴 수 있습니다:

- **Lv.10 이상 플레이어 + 정상 서버:** 서버 내 주식 거래 참여 가능
- **Lv.40 이상 + 신뢰도 1,500+:** 모든 서버를 넘나드는 글로벌 주식 참여 가능

## 서버 어드민 가이드

서버 신뢰도를 높이려면:

1. 적극적으로 봇 사용을 장려하세요 — 활성 유저 수가 신뢰도의 핵심
2. 세금 설정을 너무 높게 잡으면 플레이어 이탈로 이어질 수 있습니다
3. 신뢰도 1,000+ 유지 시 플레이어 경험치 +10% 보너스로 참여 유인이 높아집니다
