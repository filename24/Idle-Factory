# 11. 토지 시스템

## 개요

유저는 **토지(Land)** 위에 공장을 배치한다. Discord는 **Components v2 버튼 그리드**로 시각화한다.

## 핵심 개념 구분

| 용어                 | 정의                                                                      |
| -------------------- | ------------------------------------------------------------------------- |
| **확장 (Expansion)** | 현재 보유 토지 구역 내 잠긴 슬롯을 개별 구매해 사용 가능 슬롯을 늘리는 것 |
| **구매 (Purchase)**  | 새로운 **4×4 토지 구역** 자체를 구매해 병렬 운영하는 것 (Phase 2)         |

## 기본 구조

- **레벨 1 시작 토지**: **3×3 (9슬롯)** 무료 지급
- **최대 확장 크기**: **4×4 (16슬롯)** — 7개 슬롯 개별 구매로 확장
- 슬롯당 T1·T2 공장 1개 배치
- **T3 공장은 2×2 (4 슬롯) 차지**
- 슬롯에는 **일반 / 특수 슬롯** 구분이 있음 (아래 참고)

> Discord 메시지 한 개의 최대 Action Row는 5개, Row당 버튼 5개. 4×4는 4개 Row × 4개 버튼 = 16개로 한 메시지에 정확히 들어가며, 남는 1개 Row를 컨트롤로 사용한다.

## 슬롯 확장 (Expansion)

모든 토지 구역은 **3×3 (9슬롯)**으로 시작하며, 잠긴 슬롯을 **개별 구매**해 최대 **4×4 (16슬롯)**까지 확장한다.

- **잠긴 슬롯**: UI에서 **disabled 🟩 버튼**으로 표시 (클릭 불가)
- **슬롯 구매**: 컨트롤 Row의 `[확장]` 버튼을 통해 별도 UI에서 진행
- 총 확장 가능 슬롯: **7개** (3×3 → 4×4)
- **1번째 구역**: 골드만으로 확장
- **2번째 이후 구역**: 레벨 조건 + 골드로 확장

### 잠금 슬롯 배치 초기 상태

```
[ ][ ][ ][🟩]
[ ][ ][ ][🟩]
[ ][ ][ ][🟩]
[🟩][🟩][🟩][🟩]
```

3×3 영역(좌상단 9칸)이 활성, 나머지 7칸이 locked.

### 슬롯 확장 비용

플레이어가 임의의 잠긴 슬롯을 선택해 구매하며, **비용은 해당 구역에서 몇 번째 구매인지**에 따라 결정된다.

**비용 공식:**

```
슬롯_k_비용 (N번째 구역) = 5,000 × 10^(N-1) × 2^(k-1)
```

- N: 토지 구역 번호 (1~5)
- k: 구역 내 구매 순서 (1~7번째)

## 공장 크기

| Tier                          | 차지 슬롯 |
| ----------------------------- | --------- |
| T1 (농장, 광산, 목재소, 유전) | 1 × 1     |
| T2 (제철소, 정유소 등)        | 1 × 1     |
| T3 (자동차, 전자, 식품)       | **2 × 2** |

→ 4×4 토지에는 T3 공장 최대 4개까지 배치 가능하지만, T1/T2 운영 공간도 남겨야 하므로 실질적으로 T3 2~3개 + T1/T2 조합이 일반적.

## 특수 슬롯 (자연자원 매장지)

토지 생성 시 랜덤으로 특수 슬롯이 배치됨. 해당 슬롯에 적합한 공장을 지으면 **추가 보너스**.

| 특수 슬롯 | 이모지 | 효과                  |
| --------- | ------ | --------------------- |
| 광맥      | 🪨     | 광산 생산량 +20%      |
| 비옥한 땅 | 🌱     | 농장 생산량 +20%      |
| 숲        | 🌳     | 목재소 생산량 +20%    |
| 유전지    | 🛢️     | 유전 생산량 +30%      |
| 수로      | 💧     | 인접 농장·제분소 +10% |

→ 일반 공장도 특수 슬롯 위에 지을 수는 있지만 보너스 없음.  
→ 특수 슬롯은 잠긴 슬롯에도 배치될 수 있음 — 구매 전까지는 보너스 미적용.

## 인접 시너지 (A-2)

공장이 체인 관계로 인접(상하좌우)하면 생산 보너스.

| 조합              | 효과               |
| ----------------- | ------------------ |
| 광산 ↔ 제철소     | 제철소 생산 +10%   |
| 유전 ↔ 정유소     | 정유소 생산 +10%   |
| 농장 ↔ 제분소     | 제분소 생산 +10%   |
| 목재소 ↔ 가구공장 | 가구공장 생산 +10% |
| 제철소 ↔ 자동차   | 자동차 생산 +5%    |
| 정유소 ↔ 자동차   | 자동차 생산 +5%    |
| 제분소 ↔ 식품     | 식품 생산 +5%      |
| 수로(특수) ↔ 농장 | 농장 생산 +10%     |

**중첩 규칙**: 여러 시너지가 겹치면 합산, **공장당 최대 +30%** clamp.

## Discord 시각화 — Components v2 버튼 그리드

4×4 그리드를 **항상 16개 버튼**으로 표시한다. 잠긴 슬롯은 disabled 버튼으로 렌더링.

```
┌ Row 1 (슬롯 0~3) ────────────────┐
│ [▫] [▫] [▫] [🟩 disabled]        │
├ Row 2 (슬롯 4~7) ────────────────┤
│ [▫] [▫] [▫] [🟩 disabled]        │
├ Row 3 (슬롯 8~11) ───────────────┤
│ [▫] [▫] [▫] [🟩 disabled]        │
├ Row 4 (슬롯 12~15) ──────────────┤
│ [🟩] [🟩] [🟩] [🟩 disabled]     │
├ Row 5 (컨트롤) ──────────────────┤
│ [새로고침] [건설] [이동] [철거] [확장] │
└──────────────────────────────────┘
```

> Phase 2에서 다음 토지가 존재하면 컨트롤 Row의 `[확장]`이 `[다음 토지]`로 교체되거나 병행 표시.

### 버튼 라벨 규칙

| 슬롯 상태           | 라벨                              | 스타일               |
| ------------------- | --------------------------------- | -------------------- |
| 빈 일반 슬롯        | `▫`                               | Secondary            |
| 빈 특수 슬롯        | 해당 자원 이모지 (🪨 🌱 🌳 🛢️ 💧) | Secondary            |
| 공장 배치됨         | 공장 이모지 + 등급 (`🌾 3`)       | Primary              |
| T3 공장 앵커 슬롯   | 공장 이모지 + 등급 (`🚗 1`)       | Primary              |
| T3 공장 비앵커 슬롯 | `▪` (점유 중 표시)                | Primary(비활성)      |
| 잠금(미구매)        | `🟩`                              | Secondary (disabled) |

- 버튼 `custom_id`: `land:<landId>:slot:<index>` 형태
- 잠긴 슬롯은 `disabled: true` — 클릭 이벤트 없음
- 슬롯 확장은 컨트롤 Row `[확장]` 버튼으로만 진행

### 표시 예시 (부분 확장 후)

```
[🚗 1] [▪]    [🌾 3] [⛏️ 2]
[▪]    [▪]    [🌳]   [🟩]
[🌲 1] [🍞 1] [▫]    [🟩]
[🟩]   [🟩]   [🟩]   [🟩]
```

- 좌상단 2×2는 자동차 공장(T3)
- 4번째 열 일부 / 4번째 행 전체가 아직 잠김

## 토지 확장 흐름 (Expansion Flow)

1. 유저가 컨트롤 Row `[확장]` 버튼 클릭
2. 구매 가능한 슬롯 목록 및 비용 표시
3. 유저가 슬롯 선택 → 골드 차감 → 슬롯 활성화
4. 그리드 갱신 (disabled → 활성 슬롯)

> 슬롯별 구매 비용은 §슬롯 확장 비용의 확정 공식(`5,000 × 10^(N−1) × 2^(k−1)`)을 따른다.

## 토지 구역 구매 — 새 필지 구매 (Phase 2)

**확장과 별개로**, 16칸이 모두 채워지면 새로운 **4×4 토지 구역**을 구매해 병렬 운영한다.

| 토지 구역 | 구매 비용              | 누적 최대 슬롯 |
| --------- | ---------------------- | -------------- |
| 1번째     | 무료 (신규 가입, 3×3)  | 9 → 16 (확장)  |
| 2번째     | 1,000,000              | 32             |
| 3번째     | 10,000,000             | 48             |
| N번째     | `1,000,000 × 10^(N-2)` | `16 × N`       |

- 구매한 새 토지 구역도 **3×3 (9슬롯)으로 시작** — 레벨 + 골드로 최대 4×4까지 확장
- 최대 토지 구역 수: **5개** — 그 이상은 글로벌 신뢰도 요구 (Phase 3)
- 각 토지 구역은 **독립된 인접 시너지 그룹** (구역 간 시너지 없음)
- 각 토지 구역은 **독립된 특수 슬롯 배치**로 생성
- UI: 컨트롤 Row에 `[다음 토지]` 버튼으로 구역 간 전환

> Phase 1에서는 **토지 구역 1개 (3×3 → 확장 최대 4×4)** 로 고정. 구역 구매는 Phase 2에서 도입.

## 공장 이동 · 철거

| 행동          | 비용 / 환불                                           |
| ------------- | ----------------------------------------------------- |
| **공장 이동** | 해당 공장 **신축 비용의 25%** 지불                    |
| **공장 철거** | 해당 공장 **신축 비용의 50% 환불** (자재는 환불 없음) |

- 이동: 같은 토지 구역 내 빈 슬롯으로만. 구역 간 이동 불가. 등급·내용물 유지
- 철거: 등급 정보·업그레이드 부스터 선택 소멸, 원자재 부스터는 같이 소멸
- 이동·철거 시 **인접 시너지 재계산**

## 특수 슬롯 생성 규칙

- 슬롯당 특수 생성 확률: **15%** (잠긴 슬롯 포함 전체 16칸 대상)
- 4×4(16슬롯) 기대값: **약 2~3개**
- 종류는 랜덤 (광맥 / 비옥한 땅 / 숲 / 유전지 / 수로 중 선택)
- 한 토지에 **같은 종류 특수 슬롯 최대 2개** (편중 방지)
- 새 토지 구역 구매 시 **독립적으로 재추첨**
- **리롤 불가** — 고정. 새 토지 구매로만 재추첨 기회 획득

### 생성 로직 (의사 코드)

```
for each slot in new_land.slots:  // 잠긴 슬롯 포함 16칸
    if random() < 0.15:
        available_types = [type for type in SPECIAL_TYPES if count[type] < 2]
        slot.type = random.choice(available_types)
    else:
        slot.type = 'normal'
```

## 데이터 구조 (제안)

```ts
interface Land {
  id: string
  userId: string
  index: number // 1-based, 유저의 몇 번째 토지 구역인지
  width: number // 현재 활성 너비 (최초 3, 최대 4)
  height: number // 현재 활성 높이 (최초 3, 최대 4)
  slots: Slot[] // 항상 4×4 = 16개 슬롯 저장 (locked 포함)
}

interface Slot {
  x: number
  y: number
  type: 'normal' | 'ore' | 'fertile' | 'forest' | 'oil' | 'water'
  locked: boolean // true면 disabled 버튼, 구매 전
  factoryId: string | null
}

interface Factory {
  id: string
  userId: string
  landId: string
  type: FactoryType
  grade: number // 1~10
  size: { width: number; height: number } // T1/T2는 {1,1}, T3는 {2,2}
  anchor: { x: number; y: number }
}
```
