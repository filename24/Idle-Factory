# 11. 토지 시스템

## 개요

유저는 **토지(Land)** 위에 공장을 배치한다. Discord는 **Components v2 버튼 그리드**로 시각화한다.

## 기본 구조

- 기본 토지 크기: **4 × 4 (16 슬롯)**
- 슬롯당 T1·T2 공장 1개 배치
- **T3 공장은 2×2 (4 슬롯) 차지**
- 슬롯에는 **일반 / 특수 슬롯** 구분이 있음 (아래 참고)
- 기본 토지 내부는 확장되지 않음 — 16칸이 채워지면 **새 토지(두 번째 필지) 구매**로 확장 (Phase 2)

> Discord 메시지 한 개의 최대 Action Row는 5개, Row당 버튼 5개. 4×4는 4개 Row × 4개 버튼 = 16개로 한 메시지에 정확히 들어가며, 남는 1개 Row를 컨트롤(새로고침·모드 전환·토지 이동 등)로 사용한다.

## 공장 크기

| Tier                          | 차지 슬롯 |
| ----------------------------- | --------- |
| T1 (농장, 광산, 목재소, 유전) | 1 × 1     |
| T2 (제철소, 정유소 등)        | 1 × 1     |
| T3 (자동차, 전자, 식품)       | **2 × 2** |

→ 4×4 토지에는 T3 공장 최대 4개까지 배치 가능하지만, T1/T2 운영 공간도 남겨야 하므로 실질적으로 T3 2~3개 + T1/T2 조합이 일반적.

## 특수 슬롯 (자연자원 매장지)

토지 생성 시 랜덤으로 특수 슬롯이 배치됨. 해당 슬롯에 적합한 공장을 지으면 **추가 보너스**.

| 특수 슬롯 | 이모지 | 효과                  |
| --------- | ------ | --------------------- |
| 광맥      | 🪨     | 광산 생산량 +20%      |
| 비옥한 땅 | 🌱     | 농장 생산량 +20%      |
| 숲        | 🌳     | 목재소 생산량 +20%    |
| 유전지    | 🛢️     | 유전 생산량 +30%      |
| 수로      | 💧     | 인접 농장·제분소 +10% |

→ 일반 공장도 특수 슬롯 위에 지을 수는 있지만 보너스 없음.

## 인접 시너지 (A-2)

공장이 체인 관계로 인접(상하좌우)하면 생산 보너스.

| 조합              | 효과               |
| ----------------- | ------------------ |
| 광산 ↔ 제철소     | 제철소 생산 +10%   |
| 유전 ↔ 정유소     | 정유소 생산 +10%   |
| 농장 ↔ 제분소     | 제분소 생산 +10%   |
| 목재소 ↔ 가구공장 | 가구공장 생산 +10% |
| 제철소 ↔ 자동차   | 자동차 생산 +5%    |
| 정유소 ↔ 자동차   | 자동차 생산 +5%    |
| 제분소 ↔ 식품     | 식품 생산 +5%      |
| 수로(특수) ↔ 농장 | 농장 생산 +10%     |

**중첩 규칙**: 여러 시너지가 겹치면 합산, **공장당 최대 +30%** clamp.

## Discord 시각화 — Components v2 버튼 그리드

4×4 토지를 버튼 16개 + 컨트롤 Row 1개로 표현한다.

```
┌ Row 1 (슬롯 0~3) ┐
│ [▫] [▫] [▫] [▫] │
├ Row 2 (슬롯 4~7) ┤
│ [▫] [▫] [▫] [▫] │
├ Row 3 (슬롯 8~11)┤
│ [▫] [▫] [▫] [▫] │
├ Row 4 (슬롯 12~15)┤
│ [▫] [▫] [▫] [▫] │
├ Row 5 (컨트롤) ───┤
│ [새로고침] [건설] [이동] [철거] [다음 토지] │
└──────────────────┘
```

### 버튼 라벨 규칙

| 슬롯 상태           | 라벨                              | 스타일          |
| ------------------- | --------------------------------- | --------------- |
| 빈 일반 슬롯        | `▫`                               | Secondary       |
| 빈 특수 슬롯        | 해당 자원 이모지 (🪨 🌱 🌳 🛢️ 💧) | Secondary       |
| 공장 배치됨         | 공장 이모지 + 등급 (`🌾 3`)       | Primary         |
| T3 공장 앵커 슬롯   | 공장 이모지 + 등급 (`🚗 1`)       | Primary         |
| T3 공장 비앵커 슬롯 | `▪` (점유 중 표시)                | Primary(비활성) |
| 잠금(미사용)        | `🔒`                              | Danger(비활성)  |

- 버튼 `custom_id`: `land:<landId>:slot:<index>` 형태
- 클릭 시 슬롯 상세 모달/메시지 오픈 (건설 / 이동 / 철거 / 정보)
- Row 5 컨트롤 버튼은 Primary/Success/Danger로 구분

### 표시 예시 (공장 배치 후)

```
[🚗 1] [▪]   [🌾 3] [⛏️ 2]
[▪]    [▪]   [🌳]   [🏭 2]
[🌲 1] [🍞 1] [▫]    [▫]
[▫]    [▫]   [▫]    [💧]
```

- 좌상단 2×2는 자동차 공장(T3), 비앵커 슬롯은 `▪`
- `🌳` / `💧` 는 빈 특수 슬롯
- 등급은 라벨 텍스트로 병기 (이모지 상첨자 대신 일반 숫자)

## 토지 확장 — 새 필지 구매 (Phase 2)

**기본 토지 내부 확장은 없다.** 16칸이 모두 채워지면 두 번째 토지를 구매해 운영을 병렬화한다.

| 토지 슬롯 | 구매 비용              | 누적 최대 슬롯 |
| --------- | ---------------------- | -------------- |
| 1번째     | 무료 (신규 가입)       | 16             |
| 2번째     | 1,000,000              | 32             |
| 3번째     | 10,000,000             | 48             |
| N번째     | `1,000,000 × 10^(N-2)` | `16 × N`       |

- 최대 토지 개수: **5개 (80슬롯)** — 그 이상은 글로벌 신뢰도 요구 (Phase 3)
- 각 토지는 **독립된 인접 시너지 그룹** (토지 간 시너지 없음)
- 각 토지는 **독립된 특수 슬롯 배치**로 생성 — 새 토지마다 다시 추첨
- UI: 컨트롤 Row의 `[다음 토지]` 버튼으로 토지 간 전환, 현재 토지 이름/번호를 메시지 상단에 표기

> Phase 1에서는 **토지 1개(4×4)로 고정**. 새 토지 구매 시스템은 Phase 2에서 도입.

## 공장 이동 · 철거

| 행동          | 비용 / 환불                                           |
| ------------- | ----------------------------------------------------- |
| **공장 이동** | 해당 공장 **신축 비용의 25%** 지불                    |
| **공장 철거** | 해당 공장 **신축 비용의 50% 환불** (자재는 환불 없음) |

- 이동: 같은 토지 내 빈 슬롯으로만. 토지 간 이동 불가. 등급·내용물 유지
- 철거: 등급 정보·업그레이드 부스터 선택 소멸, 원자재 부스터는 같이 소멸
- 이동·철거 시 **인접 시너지 재계산**

## 특수 슬롯 리롤

**불가** — 토지 생성 시 랜덤으로 배치된 특수 슬롯은 **고정**. 운빨 요소 유지 + 장기적 토지 설계 압박.

> 불리한 배치로 느끼면 두 번째 토지 구매(Phase 2)로 재추첨 기회를 얻는 것이 정공법.

## Discord 명령어 (제안)

```
/land view [n]              # 내 n번째 토지 보기 (기본: 1)
/land build <공장> <x> <y>  # 특정 슬롯에 공장 건설
/land move <출발> <도착>    # 공장 이동 (같은 토지 내)
/land destroy <x> <y>       # 공장 철거
/land buy                   # 새 토지 구매 (Phase 2)
```

## 데이터 구조 (제안)

```ts
interface Land {
  id: string
  userId: string
  index: number // 1-based, 유저의 몇 번째 토지인지
  size: { width: number; height: number } // 기본 {4, 4}
  slots: Slot[]
}

interface Slot {
  x: number
  y: number
  type: 'normal' | 'ore' | 'fertile' | 'forest' | 'oil' | 'water'
  factoryId: string | null // 비어있으면 null, 다중 슬롯 공장은 같은 id 공유
}

interface Factory {
  id: string
  userId: string
  landId: string
  type: FactoryType
  grade: number // 1~10
  size: { width: number; height: number } // T1/T2는 {1,1}, T3는 {2,2}
  anchor: { x: number; y: number } // 좌상단 슬롯 위치
}
```

## 특수 슬롯 생성 규칙

- 슬롯당 특수 생성 확률: **15%**
- 4×4(16슬롯) 기본 토지 기대값: **약 2~3개**
- 종류는 랜덤 (광맥 / 비옥한 땅 / 숲 / 유전지 / 수로 중 선택)
- 한 토지에 **같은 종류 특수 슬롯 최대 2개** (편중 방지)
- 새 토지(Phase 2) 구매 시 **독립적으로 재추첨**

### 생성 로직 (의사 코드)

```
for each slot in new_land.slots:
    if random() < 0.15:
        available_types = [type for type in SPECIAL_TYPES if count[type] < 2]
        slot.type = random.choice(available_types)
    else:
        slot.type = 'normal'
```
