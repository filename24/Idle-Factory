# 00. 온보딩 & 초반 스타팅

## 개요

신규 유저가 `/start` (또는 `/register`) 명령을 처음 실행할 때 일어나는 일을 정의한다.

## 초기 상태 지급 (가입 즉시)

| 항목      | 지급 내용                                                | 비고                                                |
| --------- | -------------------------------------------------------- | --------------------------------------------------- |
| 초기 자금 | **1,000원**                                              | 첫 T1 공장 1개 건설 가능                            |
| 토지      | **4×4(16슬롯) 구조** 자동 생성, 좌상단 3×3(9슬롯)만 활성 | 특수 슬롯 랜덤 배치 (15% 확률, 잠금 포함 16칸 전체) |
| 창고      | **1등급 (3,000슬롯)** 자동 배치                          | 토지 슬롯을 점유하지 않는 별도 엔티티 (U-7 미정)    |
| 튜토리얼  | 퀘스트 체인 자동 시작                                    | `/quest` 로 현재 퀘스트 확인 가능                   |

> **왜 1,000원인가**: 퀘스트 1번("첫 공장 건설") 자체가 1,000원짜리 T1 공장 건설이다. 초기 자금 없이는 퀘스트를 시작조차 못하는 모순이 생기므로 최소한의 씨드머니를 지급한다.

## 튜토리얼 퀘스트 체인

퀘스트는 순서대로 진행되며, 완료 즉시 보상 지급. 건너뛰기 불가.

```mermaid
flowchart LR
    Q1[퀘스트 1<br/>첫 공장 건설] --> Q2[퀘스트 2<br/>첫 수확]
    Q2 --> Q3[퀘스트 3<br/>자재 판매]
    Q3 --> Q4[퀘스트 4<br/>공장 업그레이드]
    Q4 --> Q5[퀘스트 5<br/>두 번째 공장 건설]
    Q5 --> Done[튜토리얼 완료<br/>일반 플레이]
```

### 퀘스트 상세

| #   | 목표                        | 완료 조건               | 보상     | 누적 자금 (보상·지출 반영)                         |
| --- | --------------------------- | ----------------------- | -------- | -------------------------------------------------- |
| 1   | 첫 T1 공장 건설             | `/land build` 성공      | +1,000원 | 1,000 − 1,000(건설) + 1,000 = **1,000원**          |
| 2   | 첫 수확                     | `/harvest` 성공         | +500원   | **1,500원** (+수확 곡물)                           |
| 3   | 자재 마켓 등록              | 자재 1개 이상 마켓 등록 | +500원   | **2,000원**                                        |
| 4   | 공장 1등급→2등급 업그레이드 | `/factory upgrade` 성공 | +2,000원 | 업그레이드 **3,000원 필요** → 보상 수령 후 1,000원 |
| 5   | 두 번째 T1 공장 건설        | T1 공장 2개 이상 보유   | +1,000원 | 1,000 − 1,000(건설) + 1,000 = **1,000원**          |

> 퀘스트 보상 합계: **5,000원** (씨드머니 1,000원 별도). 단, 건설·업그레이드 지출(Q1 1,000 + Q4 3,000 + Q5 1,000 = 5,000원)이 있어 실보유 순증은 크지 않다.  
> T1 공장 추가 건설·업그레이드 자금으로 쓰기엔 빠듯하다 — 아래 각주 참조.

#### Q4 자금 조달 (모순 11 확정 — #21 결정 2)

Q4 업그레이드는 **3,000원**(03-factories.md §업그레이드 비용, 1→2 = 신축 1,000 × 3)

- 곡물 20 을 요구하는데, 퀘스트 보상만으로 모이는 현금은 **2,000원**이다
  (씨드 1,000 − 건설 1,000 + Q1 1,000 + Q2 500 + Q3 500).

**부족분은 수확·판매로 메우는 것이 정상 경로다.** Q3 는 마켓 _등록_ 뿐 아니라
**글로벌 즉시판매 체결**로도 완료되며(`marketSell.ts` 가 체결 시
`MARKET_LISTED` 를 발화), 그 경로는 판매 대금을 즉시 현금으로 지급한다. 농장
등급1 은 tick당 300원을 산출하므로 부족분 1,000원은 **4 tick = 40분**이면 채워진다.

Q4 에는 제한 시간이 없으므로 설계 위험은 "돈이 모자란다"가 아니라 "부족분을
메우는 데 너무 오래 걸려 온보딩이 정체된다"다. 따라서 검증 기준을 **자력 조달
소요 시간 ≤ 60분** 으로 정의한다 (`simulation/targets.ts`
`checkTutorialQuestFunding`, 실측 40분).

### 퀘스트 1 상세 흐름 (닭-달걀 방지)

```mermaid
flowchart TD

    Guide --> Build[유저: /land build farm 1 1]

```

## 온보딩 완료 후 상태

튜토리얼 5단계 완료 기준 유저 상태 (예시):

```
보유 자금:   ~1,000원 (건설·업그레이드 지출 반영, 판매 수익 따라 가변)
공장:        T1 2개 (농장 2등급 + α)
창고:        1등급 (3,000슬롯)
레벨:        약 Lv.1~2
토지:        3×3 활성 (공장 2개 점유, 여유 슬롯 7개 — 창고는 슬롯 비점유 별도 엔티티)
```

## 자재 기준가 (Base Price) — 경제 시스템 기반값

> **⚠️ 이 기준가가 없으면 경제 시스템 전체 검증 불가.** 직구매 가격, 업그레이드 비용 적정성, 마켓 상하한 모두 이 값에서 파생된다.

### T1 자재 기준가

| 자재 | 기준가      | 근거                                        |
| ---- | ----------- | ------------------------------------------- |
| 곡물 | **10원/개** | 저가·대량. 농장 30/tick × 10 = 300원/tick   |
| 광석 | **20원/개** | 중가·중속. 광산 15/tick × 20 = 300원/tick   |
| 목재 | **15원/개** | 저가·빠름. 목재소 25/tick × 15 = 375원/tick |
| 원유 | **50원/개** | 고가·느림. 유전 8/tick × 50 = 400원/tick    |

> T1 공장은 등급별 tick당 수익이 **300~400원/tick**으로 수렴하도록 기준가를 설정.  
> 공장 신축 비용 1,000원 ÷ tick당 수익 300원 = **약 3.3 tick(33분) 손익분기점**.

### T2 자재 기준가

| 자재     | 기준가      | 레시피 수익성 검증                                                           |
| -------- | ----------- | ---------------------------------------------------------------------------- |
| 철강     | **50원/개** | 소비: 광석 3×20=60원, 생산: 철강 5×50=250원 → **+190원/tick**                |
| 연료     | **80원/개** | 소비: 원유 2×50=100원, 생산: 연료 2×80+플라스틱 1×60=220원 → **+120원/tick** |
| 플라스틱 | **60원/개** | 정유소 부산물 (연료와 함께 생산)                                             |
| 가공식품 | **25원/개** | 소비: 곡물 5×10=50원, 생산: 가공식품 8×25=200원 → **+150원/tick**            |
| 가구     | **60원/개** | 소비: 목재 4×15=60원, 생산: 가구 6×60=360원 → **+300원/tick**                |

### T3 자재 기준가

| 자재        | 기준가       | 레시피 수익성 검증                                                       |
| ----------- | ------------ | ------------------------------------------------------------------------ |
| 자동차      | **500원/개** | 소비: 철강 3×50+플라스틱 2×60=270원, 생산: 500원 → **+230원/tick**       |
| 전자기기    | **800원/개** | 소비: 철강 1×50+플라스틱 3×60=230원, 생산: 800원 → **+570원/tick**       |
| 완제품 식품 | **150원/개** | 소비: 가공식품 4×25+연료 1×80=180원, 생산: 150×2=300원 → **+120원/tick** |

### 티어의 가치 (모순 7 확정 — #21 결정 3)

**"T2/T3 는 T1 대비 2~3배 수익" 주장은 폐기한다.** 밸런스 시뮬레이터(#31) 검증
결과 성립하지 않으며, 성립시킬 수도 없다:

| 지표                         |     T2 |         T3 |
| ---------------------------- | -----: | ---------: |
| 평균 순수익 / T1 (공장 단위) | 0.55배 |     0.89배 |
| 평균 순수익 / T1 (칸 단위)   | 0.55배 | **0.22배** |

T3 는 2×2(4칸)를 점유하므로 공장 단위와 칸 단위 배수가 **항상 4배 벌어진다**.
칸 단위 2배를 맞추려면 완제품 기준가를 자동차 500→6,300원 수준으로 올려야 하고,
그러면 공장 단위가 15.35배가 되어 같은 "2~3배" 상한을 스스로 위반한다. 두 지표를
동시에 만족시키는 기준가 조합은 존재하지 않는다.

**T2/T3 의 실제 가치는 다음 네 가지로 정의한다.**

1. **창고 부피 효율** — 창고 1칸당 가치가 T1 대비 T2 **4.78배** · T3 **42.96배**.
   같은 창고로 훨씬 큰 자산을 보관할 수 있다 (05-warehouse.md §부피 계수).
2. **후반 싱크 독점** — 창고 8~10등급 업그레이드는 자동차를 요구한다.
3. **상장 조건** — 주식 상장 자격이 T2/T3 보유를 전제한다 (08-stock.md).
4. **XP·해금 게이트** — Lv.5/Lv.10 진행의 이정표.

수익 배수는 회귀 감시용 **참고 지표**로만 리포트에 남긴다
(`simulation/targets.ts` `checkTierMultiplier`).

## 관련 스키마

참조: [`packages/database/prisma/schema.prisma`](https://github.com/filename24/Idle-Factory/blob/stable/packages/database/prisma/schema.prisma)

- `User.money` — 초기값 1,000 (BigInt)
- `UserQuest` — `questId`·`status`(IN_PROGRESS/COMPLETED/CLAIMED)·`progress` 로 퀘스트별 진행 상태 관리 (User 엔티티에 단일 카운터 필드는 없음)
- `Land` — 가입 시 자동 생성 (width:4, height:4 구조; 좌상단 3×3 만 `Slot.locked=false` 로 활성)
- `Warehouse` — 가입 시 자동 생성 (grade:1). ※ 현행 스키마엔 슬롯 좌표(slotX/slotY)가 없다 — 창고는 아직 토지 슬롯을 점유하지 않는다 (11-land.md §특수 슬롯 생성 규칙 U-7 참조)
- `GlobalMarketPrice` — `basePrice` 필드가 위 기준가 테이블과 일치해야 함
